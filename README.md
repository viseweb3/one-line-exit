A tiny deterministic program that writes the funniest single-line resignation letter it can — from an office fire warden who has finally decided to use one of the exits himself — to `/output/entry.txt` for make.fun's "The One-Line Exit" bounty. Entry by @oxcaleeev; GitHub owner viseweb3.

Bounty: https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1

## Run it

```sh
node main.ts
```

This writes the one-line resignation letter (135 characters, one line) to `/output/entry.txt`.
